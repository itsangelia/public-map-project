# 开发PDF正文内容稿

本套是排版用的内容，不是已经完成配图和引用的提交PDF。按13页正文写，每页约150–180英文词，另外加封面和参考文献；教师上限为正文15页，不含封面与参考文献。

## 文件
- Development-content-EN.docx：可直接复制排版的英文正文，已按13个页面主题分页。
- Development-content-EN-ZH.docx：同版英文＋中文理解＋配图建议＋图注，中文说明不放入英文成品。
- Development-content-EN.md：纯文字备份。
- Testing-evidence-table.docx / .csv：第10页可用的真实问题与证据状态。
- References-and-media-working-list.md：引用和素材待补项，不是已经核实齐全的最终参考文献。

## 排版
建议每页用一个明确标题、正文和1–3张有信息量的图。小图需要让老师读清；不要用大量截图填满页面。图注解释变化，不仅写界面名称。未知的旧版本数值、测试日期和人数不要补写。

正文保留了开发记录可以支持的改动，未声称正式用户研究、普遍稳定性、已证明改善归属感或已获得导师AI批准。第13页涉及授权/批准的未知状态，提交前应按真实情况更新。

必须核对：概念稿是否与正式A1一致；真实前后截图与复测记录；素材原作者及许可；unit outline引用格式；导师允许的AI范围及真实声明。若截图显示的版本与文字不同，以最终实现和真实记录修正。

本轮只编写文档内容，不修改正式地图。
