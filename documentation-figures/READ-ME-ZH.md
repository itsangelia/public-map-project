# Development Documentation 配图总包

按15页正文主题整理。每个文件夹是对应页的候选配图，不要求将所有图片都放进同一页。图片保留独立原图，缩略总览仅用于挑选。Image-index-EN-ZH.csv记录英文图注和证据类型。

## 可直接使用
已有原型页面、当前登录界面、地图/入口、饮品匹配/轮次/成品、钓鱼匹配/倒计时/角色/四结果、钢琴面板/占用提示，以及补截的聊天、许愿编辑/阅读/祝福界面。

## 准确说明来源
项目previews里的图是既有开发/受控界面截图，不是正式观众研究照片。新补的聊天、双角色和许愿图使用实际应用代码与明确的Demo A/B示例数据，网络由测试替身提供；它们说明界面，不能证明真实跨设备同步、真实祝福记录或真实玩家留言。不能把它们当历史故障的前后实测证据。

## Firebase控制台原图
你已在本对话上传Realtime Database Data和Rules画面，这两张可以直接作为真实控制台证据，不必再次寻找。内联原图没有可读取的本地文件，因此本压缩包没有擅自重画它们，也没有伪造Anonymous Enabled截图。第02文件夹提供真实配置脱敏源码、规则/认证代码及技术结构图作为可用材料。

## 没有伪造的历史证据
早期手机留白截图、历史玩家缺失截图、权限报错、Pages成功画面、旧图标与去边前后图若没有原文件，未制作成假的历史截图。相关问题已有对话/源码记录，可用真实文字摘录或已有记录支持。第13页目前是整合结果与固定入口，不能当作Pages部署成功证明。

布局上每页建议选1–3张最能支撑该页论述的图，手机图并排。原始素材与参考图仍须核实来源；本包不包含未实现的图书馆、背景音乐、代币或已删除的路灯活动。
