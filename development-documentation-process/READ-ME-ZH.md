# Development Documentation — 完整开发过程稿

本版替代此前过度围绕A1比较的写法，以你与助手的开发对话、源码和记录为依据，记录实际如何实现、遇到问题并反复修改。

- Development-Process-BILINGUAL.docx：逐段完整中英文。
- Development-Process-EN.docx / ZH.docx：单语言正文。
- Evidence-and-layout-guide-ZH.docx：每页截图/代码/反馈与英文图注位置。
- Feature-and-process-coverage.csv：功能与过程核对。

15页主题，英文约2765词；封面和参考文献另排，最终正文不能超过15页。它是正式开发文档文体，不是演讲稿。中英文对照用于阅读核对，最终排版不要默认双语全文仍能保持相同页数。

正文依次讲基础/网络→扫码与玩家可见性→手机导航→聊天→入口美术→许愿贡献→发现与祝福→饮品→钓鱼同步难度→鱼素材与结果→钢琴→整合发布→六原则→评估与作者贡献。

没有新做或编造现场测试；没有改变正式项目。待核实的研究/许可/批准事项放在来源和证据说明中。
